# 功能设计：用户状态（Presence）

> 取代原 `afk.md`。原设计（自动把人移进 AFK 频道）**不符合需求**，已废弃。

## 1. 需求

用户自己设置自己的状态，例如：

- "去拿快递了"
- "去吃饭了，20 分钟后回来"
- "挂机中"

别人能一眼看到。**不是**系统判定后自动搬人。

## 2. 状态模型

```dart
enum PresenceKind {
  online,      // 在线（默认）
  away,        // 离开
  busy,        // 请勿打扰
  custom,      // 自定义文字
}

class Presence {
  final PresenceKind kind;
  final String? text;        // 自定义文字，如"去拿快递了"
  final DateTime? until;     // 自动恢复时间，null = 不自动恢复
  final bool autoIdle;       // 是否由无操作自动置为 away
}
```

**三层含义要分清**：

| 概念 | 谁产生 | 例子 |
|---|---|---|
| 连接状态 | 网络 | 在线 / 掉线重连中 |
| 语音状态 | Mumble 协议 | 静音 / 闭音 / 说话中 |
| **Presence** | **用户自己** | 离开、请勿打扰、"去吃饭" |

三者互不覆盖，UI 上分开显示（名字后面的小标签 vs 名字的颜色 vs 麦克风图标）。

## 3. 怎么传给别人

### 主通道：`PluginDataTransmission`（Mumble 1.5+）

客户端发一条扩展数据，所有 Mcoo 客户端收到后更新该用户的状态：

```json
{
  "v": 1,
  "type": "mcoo.presence",
  "kind": "custom",
  "text": "去拿快递了",
  "until": 1762000000,
  "autoIdle": false
}
```

- 只发给**当前服务器内的 Mcoo 客户端**，原版客户端直接忽略这条消息，不报错、不干扰。
- 新用户进服时，向其他人请求一次状态快照（同一条消息，`type: mcoo.presence.query`）。

### 兼容通道：`UserState.comment`（可选，默认关）

想让**原版 Mumble 客户端**也看到状态，可以把状态文字写进自己的 `comment` 字段——官方客户端的"用户信息"里能看到。

- 默认**关闭**：comment 是用户的个人签名/资料，拿去放状态会覆盖用户自己的内容，属于污染。
- 开启时用固定前缀（`[状态] 去拿快递了`），恢复时自动剥掉前缀，不破坏原有 comment。

### 降级

- 服务器 < 1.5（无 `PluginDataTransmission`）：状态只在本地生效 + 可选走 comment。
- 不支持的客户端：看不到状态，但一切功能正常。

## 4. 自动离开（可选，默认开）

- 监听全局输入（桌面：键鼠；Android：触摸 + 前台状态）。
- 连续 N 分钟（默认 10）无输入 → 自动置 `away`，文字"挂机中"。
- 有输入 → 立即恢复 `online`。
- **用户手动设的状态优先**：手动设了"去吃饭"，自动逻辑不会覆盖它；手动状态带 `until` 时到期自动恢复。
- 用户可以在设置里关掉自动离开。

> 这里吸取上一版的教训：**只改显示，不搬人**。移动用户是服务端行为，用户没要求就不该做。

## 5. UI

| 位置 | 表现 |
|---|---|
| 用户列表 | 名字后跟一个胶囊标签：`离开`（灰）/ `请勿打扰`（红）/ 自定义文字（蓝，超长省略） |
| 频道树 | 频道内有人处于 away 时，频道行右侧显示一个小月亮 |
| 自己 | 底部状态栏左侧显示当前状态，点击展开菜单：在线 / 离开 / 请勿打扰 / 自定义… |
| 自定义弹窗 | 输入框 + 常用预设（吃饭、拿快递、开会、挂机）+ 时长选择（30 分钟 / 1 小时 / 不自动恢复） |
| 聊天 | 发送消息时若处于 away，消息旁显示状态小标签（可选，默认关） |

预设文案允许服务器管理员下发（放在服务器欢迎语的扩展段里），社区可以统一话术。

## 6. 与其他模块的关系

- **不影响语音**：away 状态下照常收发语音，除非用户同时静音自己。
- **不影响 AFK 频道**：本项目**不做**自动移频道。如果某天需要，那是独立功能，默认关闭。
- **插件可读**：`PresenceService` 暴露 `Stream<Presence>`，插件（L1/L3）可订阅，用来做"离开自动回复"之类。

## 7. 验收标准

- [ ] A 设置"去拿快递了"，B（Mcoo 客户端）1 秒内看到标签
- [ ] A 设置 30 分钟自动恢复，到点后自动变回在线
- [ ] 原版 Mumble 客户端用户在线时，收发消息、语音一切正常，无任何报错
- [ ] 关闭自动离开后，挂机 1 小时仍显示在线
- [ ] 服务器不支持 `PluginDataTransmission` 时不崩溃、不刷屏日志
- [ ] 用户自己写的 comment 不会被状态覆盖（默认配置下）
